# Nutho Device Transfer

SillyTavern extension สำหรับย้ายข้อมูลระหว่างเครื่อง (เช่น PC กับ Android/Termux) ด้วยไฟล์ `.nsync` ไม่ต้อง host, ไม่ต้องใช้ Tailscale หรือ Tunnel

Move your SillyTavern data between devices with a single `.nsync` file. Client-only, no server plugin.

## ติดตั้ง

Extensions → Install extension → ใส่ URL ของ repo นี้ หรือก๊อปโฟลเดอร์ไปที่ `data/<user>/extensions/nutho-device-transfer`

## วิธีใช้

1. **เครื่องต้นทาง:** Extensions → Nutho Device Transfer → **Export…** เปิดหน้าต่างเต็มจอ
   - มีแท็บตามหมวด (ตัวละคร, แชท, กลุ่ม, World Info, Presets, หน้าตา, Extensions, ตั้งค่า)
   - เลือก/ยกเว้น **ทีละรายการ** ได้ มีค้นหาชื่อ, เรียง, กรองตามแท็ก, เลือกจำนวนต่อหน้า และแบ่งหน้า
   - แชทจัดกลุ่มตามตัวละคร (ติ๊กทั้งตัวหรือทีละไฟล์)
   - เปิดมาทุกอย่างติ๊กไว้ และ **จำรายการที่ยกเว้น** ไว้ในเครื่องสำหรับครั้งถัดไป
   - รายการโหลดเมื่อเปิดแต่ละแท็บ (แท็บที่ไม่ได้เปิดจะส่งทุกอย่างที่ไม่ได้ยกเว้น)
2. ส่งไฟล์ `.nsync` ไปเครื่องปลายทางเอง (LINE, Drive, USB)
3. **เครื่องปลายทาง:** **Import…** → เลือกไฟล์ → หน้าต่างแบบเดียวกัน แสดงสถานะ ใหม่/อัปเดต/ชนกัน ติ๊กเลือกแล้วนำเข้า
4. จดรหัส 4 ตัวที่ขึ้นหลังนำเข้า แล้วกด "อีกเครื่องรับแล้ว" ที่เครื่องต้นทาง ครั้งหน้าจะส่งเฉพาะที่เปลี่ยน

หน้าต่างใช้สีของธีม ST และใช้เต็มจอบนมือถือ

## ย้ายอะไรบ้าง

การตั้งค่า, ตัวละคร (การ์ด + รูป), แชท, กลุ่ม + แชทกลุ่ม, World Info, presets, ธีม, พื้นหลัง, รูป Persona, Quick Replies และรายการ Extensions (ติดตั้งใหม่จาก git URL ที่ปลายทาง)

**ไม่ย้าย:** API key (ไม่เคย), sprites, Data Bank, vectors, assets

## การ merge

| กรณี | ผล |
|---|---|
| ของใหม่ | นำเข้า |
| เหมือนกันแล้ว | ข้าม |
| อีกเครื่องเปลี่ยน เครื่องนี้ไม่ได้แก้ | อัปเดต |
| แชทที่ต่อกันได้ | ต่อยอดให้ |
| แชทที่แยกทางกัน / ตัวละครที่แก้ทั้งสองฝั่ง | เก็บทั้งสอง เป็นไฟล์ใหม่ `... (จาก <เครื่อง>)` |
| การตั้งค่าที่ชนกัน | ไม่ถูกติ๊กให้ ต้องเลือกเอง |

ไฟล์ `.nsync` คือ zip ธรรมดา ไม่เข้ารหัส เก็บให้ปลอดภัยเอง

## ข้อจำกัด

- ทดสอบกับ SillyTavern 1.19 บน PC (Chrome) ยังไม่ได้ทดสอบกว้างบน Android
- ถ้าใช้กับเซิร์ฟเวอร์ที่เปิด reverse proxy อาจติดขีดจำกัดขนาดอัปโหลดของ proxy
- เซิร์ฟเวอร์ที่ host ไว้อาจตอบ 502 เป็นช่วงๆ: extension ลองใหม่ให้อัตโนมัติ ถ้าหมวดไหนยังล้ม จะข้ามหมวดนั้นและแจ้งเตือน (ไฟล์ที่ได้จะขาดหมวดนั้น และการยืนยันรับจะไม่ขยับจุด "ส่งล่าสุด")
- ตำแหน่ง/ขนาดหน้าต่างที่ลากได้ (`movingUIState`) ไม่ถูกย้าย เพราะเป็นพิกเซลของหน้าจอแต่ละเครื่อง
- ถ้าติดตั้งซ้ำทั้งใน `public/scripts/extensions/third-party/` และ `data/<user>/extensions/` ST จะใช้ชุดแรกเสมอ ให้เหลือชุดเดียว
